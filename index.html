If you see this page, GitHub Pages is serving your site correctly.

To publish from GitHub Pages:

  1. Go to the repository Settings → Pages
  2. Under "Build and deployment", select the branch you'd like to publish (usually the default branch) and the folder (/ (root) or /docs)
  3. Save. The site will be available at https://dorpnay.github.io/myAI (case-insensitive)

If your site still doesn't show, check for a CNAME, custom domain DNS, or a build error in the Pages settings.
